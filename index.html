Project Description

This expert system helps identify learning disorders in students by analyzing symptoms using the Certainty Factor method. It provides a structured approach for early detection, enabling educators at SMP Islam Plus As Syarifiyyah to offer timely and appropriate support.

The story

Constraints in detecting early learning disabilities in schools, such as those experienced at SMP Islam Plus As Syarifiyyah, point to the need for a more effective approach in recognizing students who require special attention. In the face of this challenge, technological advances provide new opportunities for schools to address the problem with a more structured and appropriate approach. Expert system technology is starting to be recognized as an innovative solution to assist data-driven decision-making in various fields. One of the appropriate methods to support the expert system in this task is the Certainty Factor method, which is designed to handle uncertainty in symptom assessment.

OUR APPROACH

Through Certainty Factor-based analysis, this system can assess the symptoms that appear in students with a high level of certainty. Based on this, the author will develop an “Expert System for Early Detection of Learning Disorders in Students of SMP Islam Plus As Syarifiyyah with Certainty Factor Method”. The application of this solution not only increases the efficiency of time and educators, but also supports the creation of a more inclusive education, where every student can get attention and guidance according to their needs. This allows them to develop according to their potential. Thus, the use of expert system applications based on Certainty Factor at SMP Islam Plus As Syarifiyyah can be a strategic step in creating a learning environment that is more adaptive and responsive to the challenges faced by students.

Project Description

The Problem Log application is a battery/charger problem logging and tracking system designed specifically for PT Century Batteries Indonesia. The system enables the QA department to document problems in real-time, perform root cause analysis, and implement solutions more efficiently. With comprehensive reporting features, management can make informed decisions based on historical data and problem trends.

The story

PT Century Batteries Indonesia faced challenges in managing and tracking battery/charger issues that occurred across their various product lines. Previously, problem recording was done manually using paper forms, which led to difficulties in tracking resolution status, analyzing problem trends, and identifying areas that required improvement. This led to slow problem resolution and inefficiencies in the production process.

OUR APPROACH

I developed a web-based application with an intuitive and responsive interface, designed to be accessed from various devices on the job site. The system has key features including issue logging with structured categories, resolution status tracking, an automated escalation system for unresolved issues, root cause analysis with the 5-Why method, and an analytics dashboard for issue trend visualization. Implementation involves intensive training for users and integration with existing ERP systems to ensure data consistency and successful adoption.
